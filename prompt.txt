## 1. Code.gs — Backend JSON API

เปลี่ยน GAS จากการใช้ `HtmlService` เสิร์ฟเว็บ ให้เป็น API เท่านั้น

ข้อกำหนด:

* ใช้ `doGet(e)` และ `doPost(e)`
* รับ route ผ่าน `action`
* ใช้ explicit allowlist
* ห้ามใช้ `eval()`, `this[action]()` หรือ dynamic function execution
* เรียก business function เดิม
* ห้ามเปลี่ยนชื่อ Sheet, column schema, function หรือ business logic โดยไม่จำเป็น
* GET ใช้สำหรับ read operation
* POST ใช้สำหรับ write operation
* validate action, payload, required field และ data type ที่ API entry point
* sanitize error ก่อนส่งกลับ Frontend
* ห้ามคืน stack trace, PIN, token, secret, Spreadsheet ID หรือ internal config

ทุก response ต้องใช้:

```javascript
ContentService
  .createTextOutput(JSON.stringify(result))
  .setMimeType(ContentService.MimeType.JSON);
```

รูปแบบ response:

```javascript
{ success: true, data: {} }
```

หรือ:

```javascript
{
  success: false,
  error: {
    code: 'ERROR_CODE',
    message: 'Safe message'
  }
}
```

write operation ที่เสี่ยง duplicate, stock ผิด, running number ซ้ำ หรือ concurrent update ต้องใช้ `LockService` และ release ใน `finally`

ห้ามใช้ method ที่ไม่มีจริง เช่น:

```javascript
output.setHeader('Access-Control-Allow-Origin', '*');
```

## 2. index.html — Static Frontend

ต้องเปิดและ Deploy บน Vercel ได้โดยตรง

ข้อกำหนด:

* ไม่มี `HtmlService`
* ไม่มี `google.script.run`
* ไม่มี `<? ?>`, `<?= ?>`, `<?!= ?>`
* ไม่มี GAS include หรือ template variable
* link `style.css`
* โหลด `app.js`
* รักษา DOM id, class, form, modal, validation, responsive layout และ UI flow เดิม

ใช้:

```html
<link rel="stylesheet" href="./style.css">
<script src="./app.js" defer></script>
```

รวม `Report.html` เดิมเข้า `index.html`

รองรับ URL:

```text
/?view=report&type=daily
/?view=report&type=monthly
/?view=report&type=yearly
```

เมื่อ `view=report` ให้แสดง report view และซ่อนหน้าหลัก โดยอ่านค่าจาก `URLSearchParams`

## 4. app.js

รวม JavaScript ของหน้าหลักและหน้ารายงานไว้ไฟล์เดียว

สร้าง API client กลาง:

```javascript
const API_URL =
  window.APP_CONFIG?.apiUrl ||
  'PUT_GAS_WEB_APP_URL_HERE';

async function apiRequest(action, payload = {}, options = {}) {
  // GET/POST, fetch, timeout, JSON parsing, error handling
}
```

แทนที่ทุก `google.script.run` ด้วย `fetch()` ผ่าน `apiRequest()`

ต้องรองรับ:

* GET และ POST
* `AbortController` timeout
* loading state
* error state
* network error
* HTTP error
* response ว่าง
* non-JSON response
* invalid JSON
* GAS redirect หรือ login HTML
* duplicate submit protection
* stale response protection
* disable ปุ่มระหว่าง submit
* เปิดปุ่มคืนใน `finally`
* report type จาก `URLSearchParams`

ห้ามใช้:

```javascript
mode: 'no-cors'
```

ห้ามใส่ secret, PIN, token, credential หรือ Spreadsheet ID ใน Frontend

## CORS Decision

วิเคราะห์ตามข้อจำกัดจริงของ GAS Web App

ตรวจสอบ:

* redirect จาก `script.google.com`
* response จาก `script.googleusercontent.com`
* browser CORS
* preflight
* authentication redirect
* HTML login page แทน JSON

ห้ามรับรองว่า Vercel ยิงตรง GAS ได้จนกว่าจะทดสอบจาก Vercel domain จริง

หากติด CORS, redirect หรือ preflight ให้รายงานตามจริง และเสนอ Vercel Function หรือ Cloudflare Worker เป็น proxy แต่ห้ามเพิ่ม architecture หรือไฟล์ใหม่อัตโนมัติ
